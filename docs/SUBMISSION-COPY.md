Built **Valid Until** for the Binance Agent OS Mini Hackathon — Track A.

**Reasoning is not authorization.**

An AI agent can make a correct decision, then reach execution after the market conditions that justified it have changed. The permission is still valid. The premise is not.

Valid Until freezes user constraints before the market read, binds a decision to an exact Binance state, then revalidates immediately before action. If freshness, price drift, spread, liquidity or policy integrity no longer hold, the action becomes **NO LONGER VALID** and fresh reasoning is required.

`POLICY FROZEN → BINANCE STATE → DECISION RECEIPT → REVALIDATE → ALLOW / BLOCK`

No alpha claim. No live trading required. Execution integrity before action.
